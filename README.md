## Как пополнять библиотеку

По просьбе владельца от 2026-11-05 сохранять сюда все новые создаваемые для него сайты. Для каждого — отдельная папка с понятным названием, готовый HTML со встроенными ресурсами, если формат сайта это допускает, и короткая заметка: дата, назначение, дизайн, анимации, взаимодействия, точки входа в код и результаты проверки. Существующие примеры сохранять; изменения одного сайта фиксировать в истории Git.

Перед работой над новым сайтом просматривать подходящие примеры и адаптировать их идеи к задаче. Репозиторий — библиотека примеров и проектных заметок, не автоматическое переобучение модели.
